# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

### Added

- Portfolio README, MIT license, contributing guide, code of conduct and security policy.
- GitHub CI (Linux checks), release workflow, issue and PR templates, Dependabot.

## [1.0.0] - 2026-08-02

### Added

- Current weather and forecast for a city (temperature, humidity, wind, sunrise and sunset) from the OpenWeatherMap API.
- City search and browser geolocation.
- Bootstrap interface with Weather Icons and Balloon CSS tooltips.

### Security

- The hard-coded OpenWeatherMap API key was replaced by a placeholder.
